# Environment variable inventory (no secret values)

> **Partly superseded on 2026-11-28.** References to Azure (Key Vault, Application Gateway, Container Apps, Terraform, Azure Monitor) belong to the rejected Azure proposal. The current plan is [vercel-architecture.md](vercel-architecture.md). Domain purchases are not authorised: staging uses the `*.vercel.app` address.

**Source of truth:** `packages/config/src/env.ts`. Production refusal rules are in `productionIssues()`.

This file lists every variable the deployed services read: where its value comes from in Azure, and what staging and production use. **No secret value appears here or anywhere in git.**

Legend for "Source":
- **TF**: set by Terraform as a plain app setting (`infra/azure/modules/platform/apps.tf`).
- **KV-gen**: generated by Terraform into the environment Key Vault and referenced by the app.
- **KV-op**: put into Key Vault by an operator after founder approval. Never in Terraform or git.
- **Build**: baked in at image build time.

## Data stores

| Variable | Secret | Source | Notes |
|---|---|---|---|
| `DATABASE_URL` | **yes** | KV-gen `database-url` | `sslmode=require`, private DNS name of the flexible server. Admin login for now. 8B adds a least-privilege app role and Entra ID authentication. |
| `REDIS_URL` | **yes** | KV-gen `redis-url` | `rediss://` on port 6380 with the access key. 8B evaluates Entra ID auth for Redis. |
| `STORAGE_DRIVER` | no | TF | **New (8B, C-21):** `azure-blob` on Azure, `s3` locally |
| `STORAGE_ACCOUNT_URL` | no | TF | **New (8B):** blob endpoint, reached through the private endpoint |
| `AZURE_CLIENT_ID` | no | TF | Selects the user-assigned managed identity for Blob and Key Vault access |
| `STORAGE_BUCKET` | no | TF | `private` container |
| `STORAGE_MEDIA_BUCKET` | no | TF | `media` container |
| `STORAGE_REGION` | no | TF | `uaenorth` |
| `STORAGE_ENDPOINT` / `STORAGE_ACCESS_KEY` / `STORAGE_SECRET_KEY` | yes (keys) | not used on Azure | S3 only (local SeaweedFS). On Azure the Blob adapter uses managed identity, so no storage keys exist (shared-key access is disabled on the account). | `UPLOAD_MAX_BYTES` | no | default | 10 MB. The WAF body limit is set above it (15 MB). |
